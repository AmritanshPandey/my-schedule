# Asset Recombination Matrix

**Lens:** Capabilities & Assets · **Method 12 of 21** · **Output:** `opportunity-output/12-asset-recombination-matrix.md`

**Question:** What new value appears when assets the business already owns are combined?

## Why it matters

Data plus expertise, or a customer base plus a new channel, can create offers no competitor can copy quickly.

## Use when

- Data-rich, expertise-rich or audience-rich businesses.
- Pairs well with AI: data + model + workflow.

## Needs

- Inventory of assets by type
- Business profile (`opportunity-output/business-profile.md`)

## Steps

1. List assets by type: expertise, data, technology, customer relationships, brand, content, partnerships, distribution.
2. Pair assets across types and write the combined offer in one line (for example, "claims data + clinical expertise → benchmarking service").
3. Screen combinations: customer job served, rights to use the data, effort, and how hard it is to copy.
4. Pick the combination to test and the smallest test.

## Checks

- [ ] Assets classified by type.
- [ ] Each combination names a customer job.
- [ ] Data rights checked.
- [ ] Material claims labeled per `references/evidence-rules.md`

## Output

- Asset inventory
- Combination matrix
- Screened shortlist
- Combination to test
- **Signals for the map:** 1–3 candidate opportunities this supports or weakens, each with strength (strong / moderate / weak / assumed) and source IDs

## Reading the signal

A combination using assets competitors lack, with a named customer job, is a strong advantage signal; unclear data rights weaken it.
