# Value Chain Opportunity Map

**Lens:** Capabilities & Assets · **Method 10 of 21** · **Output:** `opportunity-output/10-value-chain-opportunity-map.md`

**Question:** Which activities create value the business is not capturing, or cost more than they are worth?

## Why it matters

Opportunities hide in the chain: an activity customers value that is given away free, or one done badly that a partner does well.

## Use when

- Operations-heavy businesses, or when margins are under pressure.

## Needs

- Activities from inbound to after-sales
- Cost and value data where available
- Business profile (`opportunity-output/business-profile.md`)

## Steps

1. Map primary and support activities in 6–10 steps.
2. For each: value to customer (high / medium / low), cost to us, how well we do it versus others. Label evidence.
3. Find mismatches: high value but uncaptured (charge for it or productize it), high cost but low value (simplify, automate or outsource), strong capability used only internally (sell it).
4. Pick the stage to act on and the move.

## Checks

- [ ] Activities cover the full chain.
- [ ] Ratings labeled.
- [ ] Mismatches tied to a move.
- [ ] Material claims labeled per `references/evidence-rules.md`

## Output

- Value chain table
- Mismatches
- Stage to act on
- **Signals for the map:** 1–3 candidate opportunities this supports or weakens, each with strength (strong / moderate / weak / assumed) and source IDs

## Reading the signal

An uncaptured high-value activity is a moderate-to-strong value-capture signal.

*Method origin: Michael Porter.*
