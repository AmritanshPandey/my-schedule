# Business Model Canvas

**Lens:** Offer · **Method 06 of 21** · **Output:** `opportunity-output/06-business-model-canvas.md`

**Question:** How would this opportunity create, deliver and capture value, and which block is most likely to break?

## Why it matters

A good product inside a broken model fails. The canvas shows what changes versus today and where the risk concentrates.

## Use when

- The opportunity needs a new customer, channel, revenue model, partner or delivery process.

## Needs

- Opportunity description
- Current business model
- Constraints (money, people, partners)
- Business profile (`opportunity-output/business-profile.md`)

## Steps

1. Fill the nine blocks: segments, value proposition, channels, relationships, revenue streams, key resources, key activities, key partners, cost structure. Label each block's evidence; assumptions are `[HYPOTHESIS]`.
2. Compare with today's model: which blocks stay, which change.
3. Find the weakest link: least evidence, most dependency, or hardest execution.
4. State what must be true for that block to hold, and the cheapest test.

## Checks

- [ ] Every block labeled.
- [ ] Changes versus today named specifically.
- [ ] Weakest link chosen by risk.
- [ ] Material claims labeled per `references/evidence-rules.md`

## Output

- Canvas (nine blocks, labeled)
- What changes vs today
- Weakest link and what must be true
- First thing to validate
- **Signals for the map:** 1–3 candidate opportunities this supports or weakens, each with strength (strong / moderate / weak / assumed) and source IDs

## Reading the signal

A model needing few changed blocks, with evidence for revenue and channel, is a strong value-capture signal.
