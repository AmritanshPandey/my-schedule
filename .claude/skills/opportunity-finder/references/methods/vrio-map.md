# VRIO Map

**Lens:** Capabilities & Assets · **Method 09 of 21** · **Output:** `opportunity-output/09-vrio-map.md`

**Question:** Which resources give a real, lasting advantage, and which are underused?

## Why it matters

Advantage claims are often things competitors also have. VRIO separates parity from advantage.

## Use when

- Any route that needs to answer "why us?".

## Needs

- List of resources and capabilities with evidence
- Business profile (`opportunity-output/business-profile.md`)

## Steps

1. For each resource ask: Valuable (does it help customers or reduce cost)? Rare (do few competitors have it)? Inimitable (hard to copy: history, data, relationships, know-how)? Organized (are we set up to use it)?
2. Answer each with yes / partly / no and the evidence. Rarity and inimitability need competitor evidence or are `[HYPOTHESIS]`.
3. Classify: disadvantage, parity, temporary advantage, unused advantage (V, R, I but not O), sustained advantage.
4. Name the most underused resource: high VRI, low O.

## Checks

- [ ] Each answer has evidence or a label.
- [ ] Rarity checked against named competitors.
- [ ] Underused resources named.
- [ ] Material claims labeled per `references/evidence-rules.md`

## Output

- VRIO table
- Classification
- Underused resource and what organizing it would take
- **Signals for the map:** 1–3 candidate opportunities this supports or weakens, each with strength (strong / moderate / weak / assumed) and source IDs

## Reading the signal

A sustained or unused advantage that a candidate relies on is a strong advantage signal; parity is neutral.

*Method origin: Jay Barney.*
